# Recipient evidence tests

These are static handoff specimens for testing whether a recipient understands
the exact scope of an Orphograph receipt. They are not records of live anchors,
completed releases, approvals, or external delivery.

Each package contains a specimen handoff, exact proof/non-proof statements, and
an acceptance interview. A test passes only if the recipient can explain the
time bound, reproduce the indicated digest/root check, and reject the listed
unsupported inferences.

- `agent-action/`: a text record describing an alleged agent action.
- `dataset-model-release/`: a dataset-bundle commitment associated with a model release.
- `software-release/`: individual artifact receipts associated with a software release.

All identifiers and digests are visibly marked placeholders. Replace them with
retained outputs from a successful test anchor before conducting an operational
recipient test. Do not represent these static specimens as Bitcoin-anchored.
