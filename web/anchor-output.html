What this proves — and what it doesn't

The receipt is cryptographic proof that this exact output existed before a point in time. It is provenance, not detection: it makes no claim about whether content is human- or machine-made, and no claim of authorship. Agents can anchor programmatically through the MCP server — this page is the same anchor, by hand.

A receipt created through the API or the MCP server can additionally carry a zero-knowledge execution proof — evidence that a fixed, published hash-chain procedure produced the output while the inputs stay private. Its scope is stated plainly: it proves a fixed hash-chain procedure ran — not that a specific AI model ran. And the proving key ceremony is development-grade; we do not yet make this claim in any certified sense.
