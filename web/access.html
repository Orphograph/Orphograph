Why there is no password

Orphograph holds no files and, for pack customers, no account. A pack code is a bearer instrument — the code itself is the authority to spend, the way a bearer note is. A Standing Order is the one place an email stands in for an account, and even there the email only summons a one-time link; nothing is stored that could be taken to impersonate you. If you hold neither, you have lost nothing: a receipt and its .ots file verify against Bitcoin independently, and can be re-checked at Verify receipt forever.
