Receiving side

Check what you received.

Someone sent you a reply, a report, a file, or one step of an AI agent's work, with an Orphograph receipt. Paste it or choose the file. This page hashes it in your browser and checks the hash against the public receipt. What you paste is never sent; only the receipt id is used to fetch the public record, and every hash in that record is recomputed here rather than believed.

What a match means. This exact output existed by the time it was anchored, and has not changed since. It does not show who produced it, or that it is correct.

For the sender

Send the output with a check link: https://orphograph.com/check#r=<receipt id>. Everything after # stays in the reader's browser. For a salted anchor, add &s=<salt hex> only if the reader should be able to check it. Agents can run the same check with the MCP tool orphograph_verify_output.

Prefer to check without this office at all? The independent verifier and the proof files in each receipt's download work offline.
