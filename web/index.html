How it works

  1. You select a file

    Your file never leaves your computer.

  2. We create a cryptographic fingerprint

    A SHA-256 hash is generated locally.

  3. We timestamp it 5 times

    Using 5 independent OpenTimestamps calendars.

  4. We anchor it in Bitcoin

    The combined proof is committed to the blockchain.

  5. You receive a receipt

    Keep it. Share it. Verify it. Forever.

  1. Orphograph

    constructs the proof

    An open standard aggregates fingerprints into a Merkle tree (RFC 6962).

    provides permanence

    The tree's root is committed to a public chain no company controls.
