    Independent verification — don't trust us, check the chain

    The links below go to public, third-party services we don't run. Each one independently confirms the same fact. If any one of them shows your hash anchored, the proof holds — even if orphograph.com disappears.

    Note: a SHA-256 hash is not a Bitcoin transaction. The calendars batch many hashes into one Merkle root and that root lands in a real Bitcoin transaction (usually within ~1 hour). The .ots proof file contains the Merkle path from your hash to the block. Once block-pinned, the BTC block links below resolve.

    This receipt proves the SHA-256 above was submitted to the listed OpenTimestamps calendar servers at the time shown. The calendars aggregate hashes into Bitcoin transactions; each .ots file is independently verifiable against the public Bitcoin chain.

    To verify without trusting us, download the receipt JSON + the five .ots files from /api/receipt/<id>, then run the open-source verifier at orphograph.com/verify/ against your original file.

    Proof-of-existence only. Not a qualified eIDAS timestamp. Not legal evidence on its own. See Terms.
