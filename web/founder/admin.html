How to flip a toggle in production

Toggles are environment-controlled and require a re-deploy via Fly secrets. There is no in-app write path on purpose — this page is read-only.

Enable maintenance mode:

fly secrets set ORPHO_MAINTENANCE_MODE=1
fly deploy --remote-only

Disable checkout (sale freeze, anchoring stays live):

fly secrets set ORPHO_DISABLE_CHECKOUT=1
fly deploy --remote-only

Disable anchoring (calendars down or rate-limited):

fly secrets set ORPHO_DISABLE_ANCHORING=1
fly deploy --remote-only

Restore normal operations (clear a flag):

fly secrets unset ORPHO_MAINTENANCE_MODE
fly deploy --remote-only
